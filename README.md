# ideal-giggle
My First App

A simple Flutter mobile application with a counter feature.

## Features

- Clean Material Design UI
- Counter that increments when button is pressed
- Supports Android and iOS platforms

## Getting Started

### Prerequisites

- Flutter SDK (3.0.0 or higher)
- Dart SDK (included with Flutter)
- Android Studio / Xcode (for mobile development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/411221220-dotcom/ideal-giggle.git
cd ideal-giggle
```

2. Install dependencies:
```bash
flutter pub get
```

### Running the App

To run the app on a connected device or simulator:

```bash
flutter run
```

To build for specific platforms:

```bash
# Android
flutter build apk

# iOS
flutter build ios
```

### Testing

Run the test suite:

```bash
flutter test
```
